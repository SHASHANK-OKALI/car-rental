## 📌 Project Overview

The **Car Rental Management System** is a modern and responsive frontend web application developed using **HTML, CSS, and JavaScript**.

This project provides users with a simple and user-friendly platform where they can browse available cars, search and filter vehicles, select rental dates, calculate rental costs, make bookings, and manage their bookings.

The project was developed as part of a **Web Development Internship** to gain practical experience in frontend development, responsive UI design, JavaScript functionality, form validation, LocalStorage, Git, GitHub, and website deployment.

---

## 🎯 Project Objective

The main objectives of this project are:

- To develop a modern and responsive car rental website.
- To provide users with an easy way to browse available cars.
- To implement car search and filtering functionality.
- To create an interactive car booking system.
- To implement form validation using JavaScript.
- To calculate rental duration and total rental cost.
- To store booking information using LocalStorage.
- To understand real-world project structure and development workflow.
- To practice Git and GitHub for version control.
- To deploy the project as a live website using Render.

## 💾 Data Storage

This project uses the browser's **LocalStorage** to store booking information.

The booking data is stored locally using:

```text
carRentalBookings
```

This allows booking information to remain available after refreshing the webpage.

Since this is a frontend project, the booking information is stored locally in the user's browser and is not shared between different users or devices.

## 🚀 How to Run the Project

### Method 1 — Using Live Server

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension.
4. Open `index.html`.
5. Right-click on `index.html`.
6. Select **Open with Live Server**.
7. The website will open in your default browser.

### Method 2 — Live Website

You can directly access the deployed project:

**[🚗 Open Car Rental Website](https://car-rental-ztf3.onrender.com)**
